## 📌 نبذة عامة عن المشروع (Executive Overview)
**MatchPulse AI** هي منصة متكاملة لتحليل بيانات كرة القدم المتقدمة تجمع بين:
1. **البيانات المكانية الزمانية فائقة التردد (High-Frequency Optical Tracking Data - 25 FPS)** التي ترصد حركة 22 لاعباً والكرة لحظة بلحظة (145,006 فريم).
2. **سجل أحداث اللقاء التكتيكية (Discrete Event Stream)** متضمناً أكثر من 1,745 حدثاً حركياً (تمريرات، تسديدات، استخلاص، وتصديات).
3. **الذكاء الاصطناعي التوليدي التكتيكي (Tactical LLMs via Groq)** لإنشاء تعليق فني وبث إخباري ثنائي اللغة (العربية والإنجليزية) متزامن مع أحداث اللقاء.
4. **محركات محاكاة متصفحية هجينة (Client-Side HTML5 Canvas & Streamlit Web Engines)** تعمل بنظام ضغط ثنائي لنقل وتجسيد أحداث الـ 90 دقيقة بانسيابية 60 FPS بدون استهلاك الذاكرة.
